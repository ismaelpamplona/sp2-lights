# Volkswagen SP2 1975 — Comandos Originais

## Haste Esquerda (setas e faróis)

| Ação                          | Função                         |
| ----------------------------- | ------------------------------ |
| Para cima                     | Seta direita                   |
| Para baixo                    | Seta esquerda                  |
| Puxar em direção ao motorista | Lampejador (flash de luz alta) |
| Empurrar para frente          | Farol alto travado             |

## Haste Direita (limpador e lavador)

| Ação                          | Função                                   |
| ----------------------------- | ---------------------------------------- |
| 1ª posição para cima          | Limpador lento                           |
| 2ª posição para cima          | Limpador rápido                          |
| Puxar em direção ao motorista | Lavador (esguicho de água do para-brisa) |

## Painel Central (motorista → passageiro)

| Posição | Função                           |
| ------- | -------------------------------- |
| 1       | Interruptor dos faróis           |
| 2       | Reostato da iluminação do painel |
| 3       | Tampa cega                       |
| 4       | Tampa cega                       |
| 5       | Pisca-alerta                     |
| 6       | Ventilador                       |

## Conjunto Óptico Dianteiro

Representação simplificada:

[¹ O O ²] [² O O ¹]

Onde:

- **Farol ¹** = farol externo (próximo ao para-lama)
- **Farol ²** = farol interno (próximo ao centro do carro)

## Interruptor dos Faróis

### Desligado

Nenhuma luz externa acesa.

### 1º estágio (lanternas)

Acende:

- Lanternas dianteiras (faroletes)
- Lanternas traseiras
- Iluminação da placa traseira
- Iluminação do painel (ajustada pelo reostato)

Nenhum dos quatro faróis principais é aceso.

### 2º estágio (farol baixo)

Acende:

- Farol baixo dos faróis externos (¹)
- Lanternas dianteiras
- Lanternas traseiras
- Iluminação da placa

Representação:

[¹● O O ²] [² O O ●¹]

## Farol Alto

Acionado pela haste esquerda.

Acende:

- Faróis internos (²) — acionados pela haste (filamento único, só alto)
- Faróis externos (¹) mudam do filamento baixo para o filamento alto (lâmpada de duplo filamento)
- Indicador azul no painel

Resultado: os 4 faróis ficam acesos no modo alto.

Representação:

[¹● O O ●²] [●² O O ●¹]

## Indicadores do Painel

| Indicador | Função                                    |
| --------- | ----------------------------------------- |
| Azul      | Farol alto ligado                         |
| Verde     | Setas                                     |
| Vermelho  | Alternador / óleo (dependendo do símbolo) |

## Observações

- O interruptor dos faróis possui apenas duas posições úteis: lanternas e farol baixo.
- O farol alto é acionado exclusivamente pela haste esquerda.
- Ao ligar o farol alto, os quatro refletores dianteiros ficam acesos.
- O lavador do para-brisa é acionado pela haste direita, não por um botão no painel.
